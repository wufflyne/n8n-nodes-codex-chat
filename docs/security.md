# Security layer and dependency scope

The matched 0.1.0 companion retains the pinned n8n 2.45.6 base and adds a separately reviewable security layer. It preserves host peer majors and the lifecycle patch. The npm community package does not replace arbitrary host dependencies; its installed qualification uses the matched hardened host. Operators using another host must review that host's own dependencies and enabled features.

As researched on 2026-10-31, the layer pins MCP SDK 1.32.0, server/core 2.3.0 and node 2.1.0. Actual CLI, workflow-trigger and browser MCP paths enforce a 1 MiB request bound and 10,000 tool-input elements before expensive validation. The workflow low-level server requires its own guard; upgrading a package version alone does not enable every bound. Redirect, bearer-audience, session and experimental-task-store conditions receive separate checks.

All affected physical Undici 6/7, body-parser, follow-redirects and multer copies use compatible fixed versions. Shared Zod remains 3.25.76 with the exact maintained [3.25 backport](https://github.com/colinhacks/zod/commit/540f40974ff131ab96130b8fcc29af14bb750395). The [CVE authority rejected CVE-2023-54404](https://raw.githubusercontent.com/CVEProject/cvelistV5/ef9b6a15d90efb98c36db097d05e3b1c9e086571/cves/2023/54xxx/CVE-2023-54404.json) on October 28, 2026; the [GitHub registry advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5) still flags the version. The maintained backport and request bounds remain part of this release. Ordinary tools retain schema validation, and owned structured diagnostics never reach the caller's parser. Trusted workflow schemas and custom refinements remain executable application configuration; arbitrary user regexes are not made cost-free by payload limits.

The markdown-it 13.x smartquotes and core/inline linkify rules receive the maintained algorithms from 14.3.2 without changing the public interface. Link recognition remains enabled and the private linkify-it dependency is pinned to 5.0.2, matching the fixed implementation already in the base editor bundle. Both the physical server package and the actual emitted Markdown modules are patched. Every immutable JS/CSS asset gets a deterministic new name derived from original asset and patch hashes, with complete known-reference rewriting. Qualification primes the original browser cache and verifies the revised loaded assets at the same origin. That observed browser subset complements the full static asset-reference check; it does not imply every lazy-loaded feature was opened.

The offline OS layer uses signed, hash-pinned Alpine 3.24 packages for brotli-libs 1.2.1-r0, libcurl 8.23.0-r0 and libde265 1.1.3-r0. It verifies the original package database, exactly those three upgrades, every installed file/link and removal of obsolete library files. A temporary signed APK tool runs only during network-disabled image assembly, without package scripts, and is removed afterward. Node's bundled libraries do not substitute for fixing separate OS copies.

Changes to dependency versions, backport source, body bounds, base image or emitted assets invalidate the affected type, installation, browser and runtime evidence.
